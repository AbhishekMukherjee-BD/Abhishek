📁 INBOX DROPZONE - DROP YOUR RAW WORK IMAGES HERE
========================================================================

HOW TO USE:
1. Drag and drop any raw image file (PNG, JPG, WebP, SVG, GIF) directly into this folder.
2. Aspect ratio does NOT matter (16:9, 4:3, 1:1, ultrawide, etc.). 
   Your original image bytes are preserved with 100% lossless fidelity.
   Cropping and zooming are handled automatically in the browser via 
   high-performance GPU-accelerated CSS `object-fit: cover`.
3. Switch to your Work Manager Agent chat and inform the agent 
   (or the agent will automatically detect your file in this inbox).
4. The agent will ask which of the 3 work sections you want to place it in,
   collect all required schema details, and move the file into the correct
   numbered slot in:
   - 01-main-page/
   - 02-work-carousel/
   - 03-work-library/<category>/
